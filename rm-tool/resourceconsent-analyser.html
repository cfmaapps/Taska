💾 Saving & Resuming Progress

  • Ticks, flags, notes, and project-management details are auto-saved in your browser whenever you make a change.
  • Progress is stored per consent (by RM reference), so different consents don't overwrite each other.
  • Click Save to download a .json backup — use this if you switch computers or browsers.
  • Drop a saved .json progress file on the upload screen to fully restore a previous session.
  • Re-open the same HTML file and load the same PDF - your ticks, flags, notes, and project-management setup are restored automatically.

⚠ Browser storage may be cleared if you clear browsing data. Always export a JSON backup for long-term storage.
